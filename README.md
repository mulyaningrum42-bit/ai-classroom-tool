# Classroom AI

A polished, responsive interface prototype for a classroom assistant that combines student check-in, random selection, AI questions, and answer feedback.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Current interface

- Teacher dashboard with attendance and session metrics
- Quick session setup for topic and answer mode
- Face scan and session-start interaction placeholders
- Random-question interaction with sample AI prompts
- Recent student activity and score cards
- Responsive layout for desktop and mobile screens

The camera, face-recognition, speech-to-text, and AI evaluation actions are intentionally represented as frontend placeholders until a backend and consent flow are connected.
